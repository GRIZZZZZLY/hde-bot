# AI Answer Redesign — Три сообщения: Суть / Ответ клиенту / Памятка

## Goal

Переработать AI-ответ с двух сообщений (Суть + инструкция для специалиста) на три:
1. **Суть** — диагноз для специалиста (без изменений)
2. **Ответ клиенту** — готовое сообщение/вопрос/инструкция для клиента
3. **Памятка** — внутренний чеклист + алгоритм решения для специалиста

## Архитектура

Единственный LLM-вызов. `_FORMAT_INSTRUCTIONS` переписывается для возврата трёх секций. `generate_ticket_summary` возвращает `(suit_line, client_line, memo_line, confidence_pct)`. `_post_ticket_history` отправляет три последовательных сообщения. Лимит вывода: **3000 токенов** (было 2000).

## Новый формат промпта

```
Ответь РОВНО тремя строками — все три обязательны:
Суть: <диагноз проблемы, бренд/модель если известны>
Клиенту: <сообщение от лица поддержки клиенту — см. правила>
Памятка: <что проверить → как решить, шаги через →>

Правила для "Клиенту":
- Вежливо, от лица поддержки, без технического жаргона
- Если проблема ясна и решение известно → готовый ответ с шагами для клиента
- Если нужна информация от клиента → уточняющий вопрос
- Если клиент должен выполнить действия самостоятельно → пошаговая инструкция
Правила для "Памятка":
- Внутренний чеклист для специалиста: что проверить/запросить у клиента → шаги решения
- Технически точно, профессиональный язык
Общие правила: не используй markdown, не добавляй ничего лишнего.
```

## Три Telegram-сообщения

### Сообщение 1 — Суть (без изменений)
```
🧠 Суть (87%): АТОЛ 30Ф — ошибка связи с ОФД, истёк сертификат.
```
Кнопки: `[👍 Верно]  [👎 Неверно]`

### Сообщение 2 — Ответ клиенту (вместо "Предложенный ответ")
```
💬 Ответ клиенту:
«Добрый день! Для восстановления связи с ОФД перейдите в личный кабинет ОФД
и обновите сертификат, затем выполните перерегистрацию на кассе.»
```
Кнопки (строка 1): `[👍]  [✏️]  [👎]`
Кнопки (строка 2): `[📤 Ответить клиенту]  [💬 Комментарий]`

Кнопка 📤 отправляет `client_line` клиенту через HDE API (как сейчас).

### Сообщение 3 — Памятка (новое)
```
📋 Памятка:
Проверить: статус сертификата в ЛК ОФД → дата последней фискализации →
версия прошивки ФН. Решение: Меню ФН → Диагностика ОФД → Обновить
сертификат в ЛК → Перерегистрация.
```
Кнопки: `[👍 Полезно]  [👎 Бесполезно]`

## Обратная совместимость

- `optimization_samples.ai_answer` продолжает хранить `client_line` (ответ клиенту) — это основной сигнал качества
- `ai_feedback_pending.answer_text` хранит `client_line` для возможности ✏️ коррекции
- Обратная связь по памятке (`memo:good/bad`) логируется но не влияет на `optimization_samples`
