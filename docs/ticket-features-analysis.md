## Поля тикета (правая панель)

| Поле | Значение (пример) |
|---|---|
| Департамент | Оборудование |
| Исполнитель | Игорь Кравцов |
| Статус | Открыто |
| Приоритет | Стандарт с... |
| Тип | Вопрос |
| SLA на выполнение | 08.04.2026 17:42 |
| Заморозить заявку | (пусто) |
| Метки | dropdown |
| ИИ, Вторая линия, Окружение | dropdowns |
| Классификация, Тип ошибки | dropdowns |
| Примечание | text field |
| Сгорел | text field |

**Действия в шапке:** Аудит, История заявок [14], Удалить, Спам  
**Ответ:** вкладки Ответ / Комментарий, кнопка Макросы, прикрепить файлы

---

## Текущий функционал бота

| Команда | Действие |
|---|---|
| `/note` | Внутренний комментарий в HDE |
| `/send` | Публичный ответ клиенту через HDE |
| `/delete` | Удалить сообщение из HDE |
| `/refresh` | Синхронизировать топики с HDE |
| `/status` | Статистика активных топиков |
| `/digest` | Утренняя сводка по тикетам |
| `/report` | Отчёт операторов в Google Sheets |

---

## Потенциальный новый функционал

| Команда | Действие | Приоритет |
|---|---|---|
| `/close` | Закрыть тикет (статус → Выполнено) | Высокий |
| `/hold` | Поставить на удержание | Высокий |
| `/info` | Показать текущие поля: статус, приоритет, SLA, департамент | Высокий |
| `/wait` | Поставить в ожидание | Средний |
| `/priority low\|medium\|high\|critical` | Сменить приоритет прямо из топика | Средний |
| `/freeze 2h` | Заморозить тикет на N часов | Средний |
| `/tag <метка>` | Добавить метку к тикету | Низкий |
| `/assign <имя>` | Переназначить на другого исполнителя | Низкий |

**Самые полезные:** `/close`, `/hold`, `/info` — самые частые действия при работе с тикетами, сейчас требуют открывать браузер.
