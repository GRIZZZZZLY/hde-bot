# Поддержка паттернов

Не добавлять глобальный запрет по одному примеру.

Для нового кандидата записать:
1. пример;
2. предполагаемый механизм;
3. контекст, где это действительно плохо;
4. минимум два нормальных контрпримера;
5. уровень: hard / soft / structural;
6. минимальную правку;
7. тест на сохранность смысла.

## Hard
Служебный артефакт или почти однозначный дефект чистового текста. Допустима детерминированная проверка.

## Soft
Сигнал только в кластере или при высокой плотности. Нужна контекстная оценка модели.

## Structural
Проблема композиции или дискурса. Не пытаться ловить одним regex.

## Eval-набор
Для каждого нового правила иметь минимум:
- положительный пример;
- отрицательный пример;
- пример ложного срабатывания;
- пример, где правка не должна менять число/дату/отрицание;
- чистый текст, который должен остаться неизменным.
